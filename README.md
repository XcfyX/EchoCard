# EchoCard

**本地优先的个人全天候记忆采集与 AI 整理工作台**（Windows 独立桌面应用）。

DJI Mic 2 自动吸取 · 手机照片双通道 · 本地语音流水线（转写 / 说话人聚类 / 音乐检测）· AI 投喂包导出与总结回流归档。

> 当前状态：**M1 骨架与安全采集** 开发中（里程碑规划见下）

## 核心特性（蓝图）

- **采集端与处理端彻底解耦**：DJI Mic 2 USB 自动吸取 + 手机照片双通道（局域网扫码 / 目录监控），预留标准 HTTP 接口可接入自研 ESP32-S3 硬件
- **离线优先、按需联网**：转写 / 声纹 / 音乐检测全部本地完成（ONNX，CUDA 加速、峰值显存 ≤ 4.5GB、自动回退 CPU）；听歌识曲与 API 总结按需触发
- **数据零丢失安全红线**：硬件清空必须「双重认亲 → 拷贝 → 大小+SHA-256 校验 → 落库 → 删单个源文件」原子流程
- **反偏见设计**：绝不删除转写片段、绝不打“废话/无关”主观标签，只附加客观音频特征元数据

## 开发环境（Windows 11 + Python 3.12）

```powershell
py -3.12 -m venv .venv
.venv\Scripts\pip install -r requirements-dev.txt
.venv\Scripts\pytest          # 运行测试（含模拟 U 盘安全状态机测试）
.venv\Scripts\python -m echocard --dev   # 启动本地服务（开发模式）
```

## 隐私与数据安全红线

1. 所有个人数据（录音 / 照片 / 数据库 / 声纹 / 导出包）只存于本地数据目录（默认 `D:\EchoCardData`，可在设置中修改），**绝不进入本仓库**
2. 设备清空开关**默认关闭**；仅当「拷贝 + 大小 / SHA-256 校验 + 落库」全部成功后才允许删除设备上的**单个**源文件，绝不格式化整盘、绝不触碰设备隐藏 / 系统文件
3. 未绑定认亲的普通 U 盘 / 相机卡绝不被触碰（USB VID + 设备根目录 `.echocard_source` 标记双重识别）
4. 反偏见：转写片段只增不删，不附加主观定性标签
